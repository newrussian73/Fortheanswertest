# Карточки сцен

В этом каталоге будут храниться утверждённые планы сцен. До получения реальных материалов и отдельного согласования не создавать карточки с монтажными решениями.

## Шаблон карточки

```md
# Сцена NN — рабочее название

- **Таймкод на таймлайне:** `00:00:00:00–00:00:00:00`
- **Плановая длительность:** `00:00`
- **Драматическая задача:** —
- **Реальные исходники:** —
  - путь к предоставленному файлу;
  - статус согласования использования.
- **Изображение и действие в кадре:** —
- **Закадровый голос / диалог:** —
- **Музыка / звук:** —
- **Титры:** —
- **Монтажные заметки:** —
- **Проверка семейных фактов:** —
```

Каждая ссылка на медиа должна вести на реально предоставленный файл из `assets/`. Оригиналы не редактируются и не удаляются.
