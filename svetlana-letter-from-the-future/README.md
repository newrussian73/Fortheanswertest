# «Светлана. Письмо из будущего»

Каркас семейного кинематографичного короткометражного фильма. На этом этапе проект содержит только структуру и документацию: исходные материалы, монтаж и экспорт не создаются.

## Технические параметры

| Параметр | Значение |
| --- | --- |
| Продолжительность | 08:30 (510 секунд) |
| Разрешение | 1920×1080 Full HD |
| Соотношение сторон | 16:9 |
| Частота кадров | 25 fps |
| Итоговый контейнер | MP4 |
| Видеокодек | H.264 |

## Концепция

Пожилая Светлана сидит в уютной комнате у окна и перелистывает старый семейный фотоальбом. История раскрывается через подлинные семейные фотографии и воспоминания о родителях Розе и Саше, муже Михаиле, дочери Алле, зяте Владике, внуке Диме, брате Марате, сестре Рае, подругах Лене, Свете и Ане, сватах Татьяне и Валерии.

## Структура

```text
assets/
  photos/             # Только переданные заказчиком семейные фотографии
  elderly_svetlana/   # Подлинные материалы с пожилой Светланой
  backgrounds/        # Фоны и текстуры, утверждённые для фильма
  music/              # Лицензированная или предоставленная музыка
  voice/              # Записи закадрового голоса и реплик
  titles/             # Графические исходники титров
scenes/               # Карточки и монтажные планы сцен
scripts/              # Манифест и будущие вспомогательные сценарии
exports/              # Готовые контрольные и финальные рендеры
```

## Порядок работы

1. Сохранить предоставленные оригиналы в соответствующих каталогах `assets/` без переименования или удаления исходных файлов.
2. Утвердить сценарий, карточки сцен и хронометраж в `scenes/`.
3. Подготовить монтажный проект в выбранной программе и связать его только с реальными, переданными материалами.
4. Выполнить проверочный и финальный экспорт в `exports/`.

## Ограничения

- Не создавать вымышленные семейные фотографии и не выдавать сгенерированные изображения за архивные.
- Не удалять, не перезаписывать и не редактировать оригинальные исходники.
- Не начинать монтаж до отдельного утверждения сценария и материалов.

## Будущие инструменты

Для монтажа подойдёт DaVinci Resolve или Adobe Premiere Pro. Для технической проверки и автоматизированного экспорта при необходимости можно использовать FFmpeg. На этапе каркаса ничего из этого не требуется и не устанавливается.
