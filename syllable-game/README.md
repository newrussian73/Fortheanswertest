# Слоговичок

Весёлая игра для дошкольников (~5 лет), чтобы учить русские слоги и учиться читать.

## Как открыть

Откройте файл `index.html` в браузере (Chrome / Safari / Edge).

Или локальный сервер:

```bash
cd syllable-game
python3 -m http.server 8080
```

Затем зайдите на http://localhost:8080

## Режимы

1. **Слушай слог** — услышь слог и найди его среди кнопок
2. **Собери слово** — сложи слоги по картинке (МА-МА, РЫ-БА…)
3. **Угадай слово** — сопоставь картинку и слоги
4. **Лопай шарики** — лопни шарик с нужным слогом

Лисичка-помощник, звёздочки, анимации и озвучка (Web Speech API, русский язык).
