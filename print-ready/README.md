# LET'S PARTY — макет под печать CMYK 80×180 см

Готовые файлы для типографской / офсетной печати.

## Что отдавать в типографию

| Файл | Назначение |
|------|------------|
| **`lets-party-30-80x180cm-CMYK-print.pdf`** | Основной файл для печати (CMYK PDF, 80×180 см) |
| **`lets-party-30-80x180cm-CMYK-150dpi.tif`** | Альтернатива: TIFF CMYK 150 dpi (крупный формат) |
| `lets-party-30-80x180cm-CMYK-native.tif` | TIFF без апскейла (исходные пиксели ≈ 85 dpi) |
| `lets-party-30-CMYK-softproof-preview.jpg` | Превью: как примерно будут выглядеть цвета после CMYK |
| `source-RGB-original.jpg` | Исходник RGB (не для печати) |

**Рекомендация:** отправляйте **PDF** или **TIFF 150 dpi**.

## Технические параметры

- **Формат:** 80 × 180 см (без полей / без bleed)
- **Цветовая модель:** CMYK
- **ICC-профиль:** FOGRA39 (coated, ISO-подобное офсетное покрытие)
- **Разрешение:** 150 dpi (TIFF / PDF) — норма для баннера / роллапа этого размера
- **Сжатие:** PDF — без потерь; TIFF 150 dpi — JPEG q95 (крупный формат); native TIFF — Zip
- **Вылеты:** не заложены (макет в обрез к краю)

## Важно про цвета

Неоновые розовые / фиолетовые / голубые в RGB частично выходят за охват CMYK.  
После конвертации свечение станет чуть мягче — это нормально для типографской печати.  
Смотрите soft-proof превью, чтобы оценить результат до тиража.

## Проверка в типографии

Попросите проверить:

1. Размер страницы / холста: **800 × 1800 мм**
2. Цвета: **CMYK**, не RGB
3. Профиль: **FOGRA39** (или ваш стандартный coated-профиль — можно перепрофилировать у них)
