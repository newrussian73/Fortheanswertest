# Подключение фотографий с телефона — следующий этап

Фотографии из ChatGPT не переносятся в этот проект автоматически: это разные приложения, и у агента нет доступа к вашему прежнему диалогу или галерее телефона.

Когда вы решите начать монтаж, достаточно одного действия: в мобильном Cursor прикрепить к сообщению один ZIP-архив с уже сохранёнными семейными фотографиями. Я сам разберу архив, присвою файлам ID из каталога и не изменю оригиналы.

Если в приложении не видно кнопки прикрепления файла, откройте этот же чат в мобильном браузере на `cursor.com/agents` и добавьте ZIP через кнопку вложения. Это не требует ручного создания папок в репозитории.

Не нужно отправлять фотографии повторно до начала монтажного этапа.
