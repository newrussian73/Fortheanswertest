# Визуальный референс — пожилая Светлана

## Утверждённый мастер-образ

Пользователь утвердил вариант `svetlana-aged-master-reference-v4.jpg` как единый художественный образ Светланы в возрасте 75–80 лет.

Этот файл хранится как артефакт текущего проекта:

`/opt/cursor/artifacts/assets/svetlana-aged-master-reference-v4.jpg`

## Постоянные признаки

- Узнаваемая внешность Светланы, основанная на предоставленных семейных фотографиях.
- Прямоугольные тёмные очки, добрый взгляд и сдержанная тёплая улыбка.
- Светло-каштановые волосы с естественной серебристой сединой.
- Естественные возрастные черты без карикатурного старения.
- Элегантная спокойная одежда, кресло, окно, старый фотоальбом.
- Реалистичная кинематографичная подача в мягком тёплом свете.

## Правило использования

Во всех будущих вставках с пожилой Светланой используется только этот мастер-образ как визуальная основа. Менять внешность, возраст, очки, причёску или характер освещения без отдельного утверждения нельзя.

Этот художественный образ используется только для рамочной истории фильма. Реальные родственники в воспоминаниях показываются только на подлинных семейных фотографиях.
