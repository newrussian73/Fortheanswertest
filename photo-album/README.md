# Шаблон фотоальбома

Готовый HTML-шаблон альбома: обложка, развороты, подписи и просмотр фото на весь экран.

## Открыть

Откройте файл `photo-album/index.html` в браузере.

## Заменить фото

1. Положите свои изображения в `photo-album/assets/`
2. Замените файлы:
   - `cover.png` — обложка
   - `page-01.png` … `page-04.png` — развороты
   - `portrait.png`, `memory.png` — дополнительные кадры
3. Или обновите пути `src` в `index.html`
4. Поменяйте название альбома и подписи в `figcaption`

## Рекомендации

- Обложка: 1920×1080
- Развороты: 4:3 или 16:9
- Портрет: квадрат или 3:4
